# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead: **Security > Report a vulnerability** on this repository.

Include what is affected (solution, plugin, PCF control, supplier portal, workflow), how to reproduce it and the impact you expect. We acknowledge reports within 5 working days and keep you informed until a fix is released.

## Supported versions

Only the latest release of the `OpenProject365` and `OpenProject365SupplierPortal` solutions receives security fixes.

## Scope

ProjectIQ runs in the customer's own Dataverse environment and Power Pages site. Configuration of those environments (users, security roles, authentication providers, Conditional Access) is the responsibility of the customer's administrators; [docs/en/administration.md](docs/en/administration.md) describes the roles the application ships with.
